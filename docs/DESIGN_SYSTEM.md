## Photography and AI Visuals

- Prefer real approved company photography.
- AI visuals may be used only as clearly marked concepts or after explicit approval.
- AI visuals must not be used as evidence of real technology, products, facilities, references, or capacity.

## Responsive Design

Desktop, tablet, and mobile are mandatory.

## Accessibility

Target at least WCAG 2.2 AA.

## Motion

- Use only when it improves comprehension or feedback.
- Support reduced motion.
- Avoid decorative motion that slows orientation.

## CSS Change Control

Protected files, if present:

- `global.css`
- `styles.css`
- `src/index.css`
- `base44-export/src/index.css`
- shared stylesheet or design-token files

Do not write to protected files without explicit approval for the specific change.

For variant comparisons:

1. read files,
2. report differences,
3. prepare a transfer plan,
4. obtain approval,
5. apply only the approved change.
